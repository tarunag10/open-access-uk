FOI Act 2000 guidance

20 working days

Public authorities must respond to FOI requests within 20 working days from the date of receipt. The clock starts when the request reaches the correct authority.

Batch request tips

When sending the same request to multiple authorities, tailor the subject line slightly if needed to reference local context. Each authority counts its own 20-day deadline independently.

Exemptions

Authorities may apply exemptions under the FOI Act (sections 21–44). If a request is refused, you have the right to request an internal review and then complain to the ICO.

Not legal advice

This is a tracking aid, not legal advice. Verify deadlines, routes, and rights against the current FOIA 2000 and ICO guidance.
